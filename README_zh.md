# 当前论文复现材料

科学版本 v0.4.1；按当前稿件组织的论文配套分发版。

## 内容

包括主比较、冻结/持续更新对照、月份编码、历史窗口、主干稳健性、未知结局与样本选择、
金额筛查、损失分解、受控模拟，以及 DataCo/LaDe 的论文相关结果摘要。
模拟保留完整逐日汇总、逐序列评分、配对效应、分解项、分位数、池统计及运行元数据。
代码、固定协议、特征定义、依赖、验证记录与哈希清单一并提供。

文件使用普通 CSV、JSON、Python、Markdown 和 PDF 格式；没有内部 ZIP 分卷，也不需要恢复脚本。
只需解压最外层，将仓库文件夹内的内容上传到 GitHub 仓库根目录。
原始订单按原数据来源条款自行获取；完整模拟的每日二进制数组由固定生成代码重建。
此前探索过程和重复导出的图像不作为本包内容。

## 执行

使用 Python 3.13，在仓库根目录运行：

```bash
python -m pip install -r requirements-review-lock.txt
python scripts/reproduce_paper.py --out build/review
python scripts/make_revision_figures.py
```

第一项执行入口核验输入哈希、重算主要配对区间和损失分解、重建模拟统计、生成正文数值表及模拟图，
输出 `build/review/VALIDATION.json`。第二项生成其它图形组件。
完整模拟重跑、原始 Olist 主干训练与私有预测重放命令见英文 README。

## 复现范围

请先读 `docs/REPRODUCTION_COVERAGE.md`。其中按正文和补充结果列出输入、命令与验证层级。
提供全部论文相关的核心汇总证据，不代表所有强基线、日历变体和辅助任务都已经具备独立的原始数据一键训练入口。
可从原始 Olist 重训的是现有 Core/S1 四起点主流程；其它主干及辅助任务的冻结证据、参数和部分条件重放入口保留。
默认核验不重新训练模型，也不重新生成 400 条模拟轨迹。

本包具有独立哈希，并与配套补充材料 S12 的分发包标识一致；较早的完整历史分发包仍另行保留。
代码采用 MIT 许可证，原始数据遵循各自条款。网页覆盖上传不会自动删除旧仓库文件；
若已有旧 assets 分卷，更新仓库时应移除旧分卷及其恢复脚本，避免混用不同分发形式。

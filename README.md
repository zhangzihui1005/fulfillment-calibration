## Reproduce the main statistical results

Use Python 3.13 and the tested dependency lock, from this repository root:

```bash
python -m pip install -r requirements-review-lock.txt
python scripts/reproduce_paper.py --out build/review
```

This verifies input hashes, reconstructs real-data score intervals from public daily sufficient
statistics, verifies realized-loss terms, and reconstructs simulation summaries from paired
sequence-level scores. It also checks daily simulation score identities, reads generator validation
metadata, regenerates the numerical manuscript tables and simulation figure, and writes
`build/review/VALIDATION.json`. Use a new or empty output directory.

For the other main and supplementary plot components:

```bash
python scripts/make_revision_figures.py
```

Figure 1 is preserved. Historical plot filenames and the final manuscript numbering are mapped
in the coverage document. Generating a plot from a supplied interval does not re-estimate that interval.

## Included study materials

- `evidence/e17/`: all retained primary comparator scores, paired intervals, direct calibration,
  decision screening, support, solver, training-boundary and unknown-outcome summaries.
- `evidence/r2/`: daily sufficient statistics, aligned three-contrast results, backbone comparisons,
  weekly/daily trajectories, cohort bounds and follow-up-set evidence.
- `evidence/protocols/`: model and information-time protocol, feature dictionary, origin support,
  calendar comparisons, cross-year details, availability audit, pool summaries and cohort selection.
- `evidence/E18/`: daily/weekly loss diagnostics, outcome-specific contributions and block intervals.
- `evidence/E19/`: all final simulation CSV summaries, including daily and per-sequence scores,
  paired effects, decompositions, quantiles, pool summaries and sequence metadata.
- `evidence/dataco.csv`, `evidence/lade.csv`, `evidence/lade_pairs.csv`, and the LaDe pool summary:
  auxiliary evidence reported in the paper; these tasks have different outcome semantics.
- `scripts/`, `src/`: statistical reconstruction, simulation generation, raw Olist primary training,
  saved-score recalibration and fixed-record alignment entries.
- `docs/`, `data/README.md`: protocols, validation and scope, data access and attribution.

All data files are ordinary uncompressed CSV/JSON files. There are no nested archive parts or
asset-extraction prerequisites. The original raw datasets and private real-order predictions are
not included. Older exploratory archives and duplicate plot exports are excluded.

## Recreate the complete simulation

The full 400-sequence generator, locked parameters and seeds are included. Large daily sequence
arrays are regenerated by this command rather than uploaded as hundreds of binary files:

```bash
python -c "from pathlib import Path; import shutil; p=Path('build/simulation'); p.mkdir(parents=True,exist_ok=False); [shutil.copy2(Path('evidence')/n,p/n) for n in ['protocol.json','protocol_lock.json']]"
python scripts/run_e19.py --out build/simulation --check-only
python scripts/run_e19.py --out build/simulation --workers 20
python scripts/summarize_e19.py --out build/simulation
```

Choose worker count for the machine. One numerical-library thread is used per worker. The default
review command does not generate new sequences. To verify the newly generated daily arrays with
the retained independent implementation, copy the E18 evidence beside the new E19 output first:

```bash
python -c "import shutil; shutil.copytree('evidence/E18','build/simulation/E18')"
python scripts/verify_public_results.py --out build/simulation
```

## Raw-data training and saved-score workflows

Obtain original Olist data under the terms linked in `data/README.md`, then run:

```bash
python scripts/reproduce_olist_primary.py --olist-zip /path/to/Olist.zip --out outputs/core --threads 20
```

This is the raw-data Core/S1 LR four-origin pipeline including Raw, Frozen, Expanding and history
window policies. It is not a full raw-data rerun of every CatBoost, Restricted LR, PeriodicLR,
calendar variant or auxiliary-task model. Their frozen evidence and detailed settings are retained;
the capability boundary is explicit in the coverage document.

Additional entries require separately held private records:

```bash
python scripts/replay_e17_calibration.py --archive /path/to/private_E17_archive.zip --origin O2 --out outputs/replay_O2
python scripts/align_core_comparisons.py --e17-dir /path/to/extracted_E17 --out outputs/alignment
python scripts/run_e18.py --predictions-dir /path/to/private/predictions --reference-dir evidence/r2 --out outputs/loss_diagnosis
```

`align_core_comparisons.py` requires `predictions/`, Core origin pool files, `metrics.csv`,
`paired_intervals.csv` and `unknown_outcome_bounds.csv` from the original extracted experiment.
E18 requires the twelve Core/Restricted/CatBoost origin prediction files. These commands must not
be represented as public-data-only execution.

## Version, integrity and interpretation

`INPUTS.sha256` identifies retained original evidence and code; `MANIFEST.sha256` covers this
entire distribution except itself. The manuscript distribution has its own archive checksum.
The accompanying Supplement S12 identifies this manuscript distribution. The earlier full
v0.4.1 archive remains separately identifiable by its historical hash. No new remote commit,
release tag or journal acceptance is asserted by this ZIP.

Conditional fixed-prediction intervals do not include refitting, research selection or multiplicity
uncertainty. Final-delivery cohort selection, reconstructed feedback times, and non-equivalent
auxiliary tasks remain limitations. Author-side reconstruction is not independent-person validation.

their terms. Citation metadata are in `CITATION.cff`.
